# Example sites

[Rotating cube](cube/README.md) is an AssemblyScript site demonstrating the
smolbrowse interface: a shaded, animated 3D cube drawn entirely with `pixel`
and `text`. Examples are independent of any browser implementation.

[TIP](tip/README.md) demonstrates v2 input with a playable isometric cube puzzle.
Tip a marked cube into a hole with the gold face down, using the keyboard or
clicking neighboring tiles. Includes three boards, animated tipping, undo, and
restart. Like the rotating cube, it uses AssemblyScript and ships compiled Wasm.
